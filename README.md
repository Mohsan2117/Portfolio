# Mohsan Iqbal Portfolio (Next.js Clone)

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Structure

- `public/site.css` — original portfolio styles
- `src/data/site.ts` — content (experience, projects, skills, contact)
- `src/components/` — page sections matching the live site
